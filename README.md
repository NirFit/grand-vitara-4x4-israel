# Suzuki Grand Vitara 4x4 Israel - אתר המועדון

אתר מקצועי למועדון סוזוקי גרנד ויטרה 4x4 ישראל.

## 🌐 האתר החי

**https://nirfit.github.io/grand-vitara-4x4-israel/**

## הרצה מקומית

```bash
# Python
python3 -m http.server 8080

# או עם npx
npx serve .
```

ואז פתח בדפדפן: http://localhost:8080

## מבנה הקבצים

- `index.html` - דף הבית
- `styles.css` - עיצוב
- `script.js` - לוגיקה

## תוכן האתר

- חוברת מכונאים אינטראקטיבית (NotebookLM)
- סרטון הדרכה לניווט בחוברת
- מאגר מידע (13 קישורים)
- תקנון המועדון
- סרטון מכלולי הרכב - טל צופי
- קישורים נוספים: טיולים, בורר טרנספר, צמיגים
